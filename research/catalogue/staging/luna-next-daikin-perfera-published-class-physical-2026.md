# Perfera FTXM-A / RXM-A current published classes (2026-10-11)

This separate schema candidate records seven current Daikin Europe catalogue class pairs as class identities, not full factory SKUs. Printed p.320 (ECPEN26-500, 02/2026) is pinned as HTML plus its original renderer vector and page-substrate layers. The vector/text and substrate were visually composed and reviewed; the substrate shows the merged table cell boundaries.

The candidate has 14 indoor/outdoor class records and no CTXM15A entry. The pairs are FTXM20A/RXM20A, FTXM25A/RXM25A9, FTXM35A/RXM35A9, FTXM42A/RXM42A, FTXM50A/RXM50A8, FTXM60A/RXM60A, and FTXM71A/RXM71A. Each row retains its own evidence locator and abbreviated class excerpt.

For each indoor class, the records include H/W/D casing, separate cooling-high and heating-high airflow, and preserve source m³/min tuples in evidence while storing the exact ×60 conversion in m³/h. The 20A/25A indoor high-flow cells are merged and equal in each mode. For each outdoor class, records include H/W/D casing, R-32, cooling ambient °CDB minimum/maximum, and heating ambient °CWB minimum/maximum. No outdoor airflow, capacity, charge, or electrical data is asserted.

The catalogue prints class pairings only. The exact full factory SKU suffix, full-SKU compatibility, and current France retail eligibility remain unknown; no historical A2/A5 reference is treated as an alias. The class candidate status reflects appearance in the current 2026 Europe catalogue, not sales availability.
