# Published catalogue classes: implemented bounded contract

This proposal preserves source-listed classes when a primary catalogue does not print complete factory suffixes. It does not alias those classes to historical exact SKU records.

A new explicit acceptance kind, `reviewed-class-fields`, is separate from ordinary `reviewed-fields`. Runtime metadata records `identityKind: published-class` and a source edition. An independently hash-bound receipt must verify the class header, each applied physical field/condition, the published class pairing and the source snapshots. Candidate unknowns must explicitly retain the unpublished factory suffix. Source availability remains unknown: listing in a 2026 Europe catalogue establishes an advertised class, not France stock or the status of any exact archived suffix.

A reviewed mono class pairing can select only its source-listed partner class and apply published casing and cooling high-fan volumetric flow. Unknown outdoor high-fan flow retains editable manual mass flow. The generic compressor, refrigerant charge/inventory, coil conductance and fan power remain unchanged; the source class carries no OEM performance map. Full-SKU eligibility remains `unknown`, including when the necessary class pairing agrees. Native choices and persistent model information must say “class; suffix unpublished”. A class identity never silently appears as an exact manufacturer reference.

Current source gaps:

- Perfera p.320 gives seven FTXM/RXM mono class pairings and physical rows, but its flattened HTML cannot safely associate every merged casing/flow/range cell. The pinned vector/substrate visual review has now established the applied cell associations. Existing archived A2/A5 full references remain separate.
- CTXM15A on p.320 is multi-only. It must not receive a fictitious mono outdoor pairing; current multiport profiles still lack independently qualified full family/size matrices.
- Siesta p.338 advertises ATXC-E/ARXC-E classes. Separate official Europe technical columns establish the EV1B full references; those exact profiles are accepted separately, without substituting older ATXC-C/D or FTXC references.
- The exact France ATXM/ATXF pair columns name ARXM/ARXF outdoor suffixes, not RXM/RXF. Those exact outdoor physical sources are being researched separately.

The isolated Perfera integration implements this explicit boundary for fourteen source-listed class records. All earlier accepted records and generated runtime profiles are preserved as JSON values; the new records are appended. See perfera-published-class-integration.md for source pins, limits and verification.
