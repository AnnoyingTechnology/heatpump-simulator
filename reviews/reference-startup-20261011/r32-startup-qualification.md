# R32 Reference startup qualification (isolated, 2026-10-11)

The existing ordinary inverter drive can start from rest at 2 rps/s for idealized Reference lines. Each positive accepted speed uses an actual native refrigerant cycle; exactly zero remains the passive/off path. No interpolated watts, scaled heat, fitted electrical floor, property-domain relaxation or conservation exception is needed. The one-line prototype enables `startupFromRest` only for ordinary inverter operation with every line length/elevation zero. Fixed-speed, dedicated defrost and physical-pipe admission stay separate.

Six fresh heating/cooling starts at dt0.25/0.1/0.025s pass, with first actual speeds0.5/0.2/0.05rps and improving timestep convergence. A genuine >35°C-coil restart after30s minimum-off, all-calls-Off shutdown, natural humid frost/defrost/heating return, and legacy18rps fixed start pass. The first60s warmup failed the warm-coil precondition only; extending actual heating to300s (same35°C threshold) passes. Original receipts preserve that failure. Native cycle tolerance remains0.1W, energy/water ledgers and discharge/ratio caps hold. Fault rollback is asserted when encountered, but these trajectories triggered no fault.

Fresh static bath probing closes all60 idealized points (six cold/warm heat/cool states,0.05 through18rps). Physical piping is a real limitation: several low-throughput points reject; the warm unequal two-head heating example rejects8 while18 closes. Do not enable zero-to-minimum Reference ramp for physical lines from this evidence, conceal failures with a speed retry, or claim an OEM floor. A physical transient would require an independently qualified line/valve closure or explicit refrigerant mass/internal-energy/pressure storage. The present idealized result is an honest bounded quasi-steady refrigerant approximation coupled to the existing dynamic coil/fabric stores; rotor inertia and motor starting losses remain outside it.

Replays and full source/build/vendor pins are retained in this directory; `r32-startup-qualification-results.json` indexes all receipts. All production sources, repository builds and git state were left untouched by this prototype.
