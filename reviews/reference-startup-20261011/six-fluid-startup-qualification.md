# Idealized Reference zero-to-minimum startup qualification

This isolated prototype reuses the accepted physical-displacement startup drive API from66ca8be. The Reference call enables `startupFromRest` for ordinary inverter operation only when every room pipe has zero length and zero elevation. Startup throughput rises at the configured2rps/s; each positive accepted speed is evaluated by the native conserved refrigerant model. Zero speed follows the existing passive path. Fixed-speed and dedicated defrost retain their separate commands. No electrical display interpolation, output scaling, guessed minimum power, property-domain exception or guard weakening is introduced.

This is a bounded idealized quasi-steady refrigerant-throughput approximation coupled to existing coil/fabric thermal stores. Rotor inertia, motor losses and transient line inventory/pressure equalization are outside this model.
